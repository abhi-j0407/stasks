# stasks

Personal task tracker. Nightly Today / Tomorrow / Registry planning.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). The app redirects to `/today`.

Copy `.env.example` to `.env.local` when a later phase needs env values. Do not commit secrets.

## Accounts

Personal GitHub, Vercel, Neon, and Google OAuth only. Never RaftLabs orgs, emails, or billing.
